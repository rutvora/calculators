# Simple front-end handy calculators

## How to Use
1. Copy the `sample_config.json` to another file of your desired name.
2. Update the JSON file with the inputs, outputs, constants and intermediates (calculations).
3. Add the new JSON file in the `configs.json` entry
4. Open the `index.html`

_Note: You can also host this on cloudflare pages as this is static front-end only_

### Rent-a-car comparison
Compare the costs between Evo, Modo and typical rental car companies (e.g. Avis, Hertz, National)

### EMI vs Investment Comparison
Compare the difference between paying cash for something vs taking an EMI and investing the cash-equivalent amount.  
This assumes that you have cash on hand available to invest (or pay cash, if that's the better option).
